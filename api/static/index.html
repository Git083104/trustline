Trustmap How it works

Find the parts of your code a stranger could take over.

Trustmap scans a repo or website for expired domains, deleted buckets and abandoned accounts, then tells you what to fix first.

How it works

Five layers, from raw files to a ranked fix list.

  1. Find outside URLs, buckets, and Actions uses:
  2. Check DNS, RDAP, GitHub, and bucket probes in code
  3. Investigate with an agent (live_fetch, certs, wayback)
  4. Rank with Muse; code floors set a minimum severity
  5. Report fixes, evidence, and what was checked and safe
