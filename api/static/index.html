Brief

An AI agent that scans your codebase or website, finds every outside domain, script, and cloud bucket your software depends on, and tells you which ones have expired or changed owners, so a stranger can’t quietly take over something your app already trusts.

Facts come from deterministic tools. Judgment comes from Muse Spark. The model never looks anything up and never does date math; it decides what each reference is, which check to run next, and what the evidence means. Code rules keep a claimable bucket or domain from being talked down.

Walk every file, or fetch the page and the scripts it loads, and pull out each outside address: script tags, API base URLs, CDN links, webhooks, config, CI workflows and their uses: actions, Dockerfiles, even documentation. Set aside what can’t change hands: example domains, IP literals, placeholders, well-known infrastructure.

02

Classify

Engine:
Muse Spark 1.3
Status:
Waiting

A regex finds strings but has no idea what they mean. Muse Spark reads the code around each hit and decides what it is, where it runs, and how much damage a hostile owner could do from there, as a blast radius from 0 to 3. The answer is JSON checked against a schema.

03

Investigate

Engine:
code lookups + Muse Spark agent
Status:
Waiting

Code asks who owns each address now: DNS, registration and expiry (RDAP), bucket probes, GitHub accounts and repos, platform takeover fingerprints, Tranco popularity. Then a Muse Spark agent picks the next check, such as certificate history, Wayback, or a live fetch, and stops when the evidence is enough. The model chooses tools; it never invents their results.

04

Reason

Engine:
Muse Spark 1.3 + code rules
Status:
Waiting

Muse Spark weighs how exposed each position is against the evidence and writes the risk in one sentence. Code checks every claim in that sentence against the evidence and sends it back if anything is not there. Severity floors keep a claimable bucket or an unregistered domain from being talked down.

05

Turn dozens of mixed signals into a short ranked list a developer will act on: fix today, review, or safe, each with a plain explanation and a specific fix.

Trustline finds what your software depends on, checks who owns it now, and warns you before a stranger moves in. Detection only: it never registers or claims anything.
