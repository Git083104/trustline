The problem

In 2024, polyfill.io pushed malware to 100,000+ sites. None of them changed a line of code.

01
A trusted script
<script src="https://cdn.polyfill.io/v3/polyfill.min.js">

Pasted into templates years ago. Loaded on every page view.

02
Its domain changes hands
beforeoriginal maintainer afternew, unknown owner

Same name, same URL. Nobody downstream notices.

03
Malware ships to every site that loads it
100,000+sites

The script was still trusted. Only the owner had changed.

Nobody re-checks who owns what their code trusts. Trustline does.
